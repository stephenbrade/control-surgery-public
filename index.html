Overview

Supplementary listening examples for Control Surgery. Each example is a morph: an LLM agent authors interpretable edits (gain, brightness, pitch, onset density, envelope) to the source's sketch-like control signals, and the morph engine applies them at fraction α alongside a CFG mix of source and target prompts. Drag the slider to move from the source (α = 0) to the edited target (α = 1); playback stays in place as you scrub, so you can hear the same moment of the sound at every step.

Value operators name a destination band on a corpus percentile ladder: the control curve is rescaled so its peak sits at that percentile of the signal's distribution over the training corpus, which keeps every authored edit within a magnitude the corpus actually exhibits.

Cherry-picked examples

Hand-selected morphs, one per perceptual axis. Each was authored by the agent from the source and target prompts alone; the slider walks the 11 rendered α steps. Use All steps to see the whole trajectory at a glance and Envelopes to see how the edit reshapes the sound over time.

Random examples

Uncurated cards drawn from the FoleySet source–target pairs used in the evaluation, with no filtering for quality. Every method is rendered on the same pair, seed and 11-step α grid, so the players sit side by side; Control Surgery is first in each row.
